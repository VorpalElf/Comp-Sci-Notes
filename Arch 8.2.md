## Design Process
1. Count the number of states required
2. Describe the state transition & output functions (with diagrams or tables)
3. Perform state assignment
4. Express $\delta$ and $\omega$ as optimised Boolean expressions
5. Place into the framework
⭐️ Include `reset` input to <mark style="background: #FFB86CA6;">reset to start state</mark>
💡 Include <mark style="background: #FF5582A6;">error state</mark> in accepting states
💡 Divide & Conquer, FSM for making decisions
