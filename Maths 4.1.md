## Introduction
- Set: Unordered collection of distinct objects called *elements*
- Defined in several different ways
	- Listing elements
	- Recursion
	- Predicates, e.g. All people who are your friends
- Every set defined with reference to the universal set
- Empty set: $\emptyset$

## Sets & Elements
- Equality: All sets contain the same elements
### Operators
$\cup$ : Union (i.e. OR)
$\cap$ : Intersection (i.e. AND)
$A^C$: Complement (i.e. NOT A)
$A \backslash B$ or $A-B$: Difference (i.e. (in A and not in B) $\equiv A \cap B^C$)
### Subsets
$A \subseteq B$: All elements in A exists in B
$A \subset B$: $A \subseteq B$ and $A \neq B$
