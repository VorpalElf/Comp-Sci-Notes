## Membership Function
$$\mu_{A}(x) \{ ^{1, \space if x \in A} _{0,\space if x \in A^C}$$
- When $\mu_A(x) = 1$, an element $x$ belongs to set A
- When $\mu_A(x) = 0$, an element $x$ does not belongs to set A
### Membership Table
- Complement: Flip the membership value

| $A$ | $A^C$ |
| --- | ----- |
| 1   | 0     |
| 0   | 1     |
