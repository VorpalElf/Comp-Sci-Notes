### Introduction
- Mathematically to model the uncertain world
### Sample Space
- Represented in $\Omega$
- A set of possible outcomes
- An event $\mathbb{E} \subseteq \Omega$

| Combinations   | Meaning                 |
| -------------- | ----------------------- |
| $E_1 \cap E_2$ | Both event occured      |
| $E_1 \cup E_2$ | At least A or B occured |
|                |                         |
### Probability Space
- $(\Omega, P)$ where $\Omega$ are possible outcomes, $P$ is the probability distribution
- $P$: $P(\Omega) \rightarrow [0,1]$
E.g. 
- $P(E_1 \cup E_2) = P(E_1) + P(E_2)$
- $\cup _i = \sum P(E_i)$ (i.e. countable additivity)
Discrete: $(\Omega, P)$ where $\Omega$ is finite
### Uniform Distribution
- All outcomes are equally likely
- E.g. $P(x_1) = P(x_2)$, hence $P( \{ x_1, x_2 \}) = p+p$
