## Introduction
A function that takes a function <mark style="background: #FFB86CA6;">as an argument</mark> or returns a function <mark style="background: #BBFABBA6;">as a result</mark>

### Map
```Haskell
map :: (a -> b) -> [a] -> [b]
```
`(a -> b)`: First parameter (which is a function)
