## Introduction
- LIFO (Last-in-first-out)

⭐️ Arrow operator
```C
void move(item *i, int dx, int dy) {
i->x = i->x + dx;
i->y = i->y + dy;
}
```
`i -> x` $\equiv$ `*i.x` (i.e. the member $x$ of the item pointer $i$ pointing to)
