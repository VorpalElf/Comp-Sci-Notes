## Set in Sets
### Subset vs Membership
$\subseteq$ : Element in another set
$\in$ : Set in another set
E.g. $A=\{1\}, B=\{1,2\}$
where $A \subseteq B$ and $A \notin B$
### Peano Construction
Empty sets
- $\emptyset = \{\}$: Empty set contains no elements
- $\{\emptyset\}$: Contains 1 element (the empty set)
- $\{\{\emptyset\}\}$: Contains a set that contains the empty set

## Cardinality
- Number of elements contain in a **finite set**
Rules
1. $\emptyset = 0$
2. $|A \cup B| \leq |A|+|B|$, if $|A \cup B| = 0$
3. $|A \cap B| \leq min(|A|,|B|)$
4. $|A \cup B| = |A| + |B| - |A+B|$ (i.e. A, B - A and B)
