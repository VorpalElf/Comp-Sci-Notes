## Introduction
- An assignment of **exactly one** element
- Also called mappings
## Properties of Functions
1. Injective (i.e. one-to-one)
	- If 2 outputs are the same, the inputs of those 2 should also be the same
2. Surjective (i.e. onto)
	- For every element $b$ in $B$, there is an element $a$ in $A$, such that $f(a) = b$
3. Bijective (i.e. one-to-one correspondence)
	- If it's both <mark style="background: #FFB86CA6;">injective & surjective</mark>
## Inverting Functions
- $f^{-1}(b) = a$ iff $f(a) = b$

## Image
For a function $f: A \rightarrow B$, the image is
$$Im(f) = \{ f(a) \space|\space a \in A\} = \{b \in B \space|\space \exists a \in A, \space f(a) = b \}$$
- Set of all elements in the range that the function can actually reach

## Composing Functions
- $f \circ g = f(g(a))$, for all $a \in A$
